## 每天观察五个维度

1. **操作效率**：能不能快速找到要做的事情？
2. **信息清晰**：能不能马上理解项目目前状态？
3. **状态连续**：切换页面/视图/窗口后，是否需要重新寻找信息？
4. **交互预期**：点击按钮后，结果是否符合预期？
5. **视觉舒适**：长时间使用是否疲劳，是否有不必要的视觉干扰？

## 14 天后分类

- **必须修复**：数据错误、状态丢失、关键流程中断。
- **值得优化**：高频出现、明显增加操作负担的问题。
- **暂缓处理**：低频问题、纯视觉偏好、需要大量开发才能改善的问题。
