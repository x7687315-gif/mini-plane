## 二、三个由用户拍板的决定（已写进规格）

1. **触发把手**：顶部中央胶囊把手（约 120×12px，纸色 + 钴蓝细边，悬停加宽显示「工程 Island」）。
2. **持久化**：`runtime/desktop-config.json`（原生配置）——模式与窗口位置在页面加载前即可恢复，
   与 `secret_key` 同目录，不受浏览器存储清理影响。
3. **网页版 `/island`**：与桌面面板**共用同一套多项目总览**（网页版不渲染把手与图钉窗口控制）。

## 三、规格里定死的几个关键规则

- **两个正交状态**：`displayMode`(auto_hide/pinned) × `visibility`(hidden/expanded)，
  四宫格语义逐条列明；**取消固定不自动收起**（否则用户以为按钮失灵）。
- **六个问题**：Progress / Stage / NOW / STEP / HOW / NEXT / DONE，外加 AGENT 运行状态；
  **STEP 与 HOW 只能由 Agent 通过接口上报**，缺失显示「尚未记录」，**禁止推测填充**。
- **语义红线**：Task = 计划；Worklog = 实际做了什么与结论。二者不得合并。
- **视觉例外边界**：Island 外壳 22–30px 圆角、卡片 12–16px、控件全圆角、单层淡阴影；
  普通页面仍 ≤4px，**不得**连带圆角化；圆角写在 Island 组件内部，不新建全局 token。
- **实时**：一条 overview WS 覆盖所有项目；事件只是通知，事实数据以 REST 为准；
  断线不虚报 LIVE。
- **非目标**：不做工作流引擎 / DAG / MCP / 每项目一条 WS / 全应用圆角化。
