# Mini Plane 使用指南（严谨版）

> 最后更新：2026-09-30 ｜ 适用版本：桌面单机版（pywebview + 内嵌 SQLite）
> 这份文档解决一个问题：**这东西现在到底怎么用**。分「只想用起来」和「要改代码」两条线，
> 每条都给出可直接照做的步骤；文末 FAQ 专门解释"为什么看起来复杂"。

---

## 0. 一句话：它是什么

Mini Plane 是一个**跑在你自己电脑上的项目管理软件**（仿 Plane）：工作区 → 项目 → 任务（Issue）→
评论 / 动态 / 批量 / 实时协作。**数据全部留在本机，不联网、不上传**。它以**原生窗口桌面 App**
的形式运行（不是浏览器标签页），双击图标即用。

---

## 1. 我该用哪种方式？（三选一）

| 你的情况 | 用哪种 | 需要装什么 |
|---|---|---|
| 只想打开就用（本机已配好，桌面有「Mini Plane」图标） | **A. 桌面 App** | 无需再装，双击即可 |
| 换一台新电脑，想把它跑起来 | **B. 桌面 App · 从零安装** | Python 3.12 + Node 20+ + WebView2 |
| 要改代码 / 做开发 / 跑测试 | **C. 开发模式** | 同上 + PostgreSQL 16 |

> 关键认知：**桌面 App（A/B）用内嵌 SQLite，不需要装 PostgreSQL**；只有开发/CI（C）才用 Postgres。
> 这是很多人觉得"复杂"的根源——把开发环境和运行环境混为一谈了。

## 2. A. 桌面 App：直接双击（本机已装好）

当前这台机器已经构建完毕，日常使用只有一步：

> **双击桌面「Mini Plane」图标** → 弹出原生窗口 → 输入昵称 → 进入。

- 首次会进登录页，输入一个昵称（如"北归"）点「进入」即建号并进入，**不用设密码/邮箱**。
- 之后每次双击**自动是登录态**（会话已持久化，见 §5），不再让你重新登录。
- 想关掉：直接关窗口，后台服务会**一起干净停掉**（不会残留端口占用）。
- 万一图标丢了：双击 `desktop\MiniPlane.cmd` 效果相同；或重新生成快捷方式（见 §6.4）。

## 3. B. 桌面 App：换台新电脑从零安装

前置（一次性）：
- **Python 3.12+**（`python` 在 PATH）
- **Node.js 20+**（`node` 在 PATH）
- **Microsoft Edge WebView2 运行时**（Win11 自带；Win10 若缺，装一次"Evergreen Runtime"）

在项目根目录依次执行：

```bat
:: 1) 后端依赖（建虚拟环境 + 装包，含 pywebview）
cd backend
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements\local.txt -r requirements\desktop.txt
cd ..

:: 2) 构建前端单机产物（生成 dist\mini-plane-0.2.0-local\app\server.js）
python scripts\package.py

:: 3) 打包桌面启动器 exe（生成 dist\MiniPlane\MiniPlane.exe）
backend\.venv\Scripts\python.exe desktop\build.py

:: 4) 建桌面快捷方式（指向上面的 exe）
powershell -NoProfile -ExecutionPolicy Bypass -File desktop\make_shortcut.ps1 -Exe "%CD%\dist\MiniPlane\MiniPlane.exe"
```

完成后双击桌面「Mini Plane」即可。首次运行会在
`runtime\miniplane.sqlite3` 自动建库（无需你手动迁移）。

## 4. 登录与账户（现在的逻辑，和以前不一样了）

本地单机版刻意把登录做到最简：

1. **昵称优先**：进入应用只让你填一个**昵称**。昵称没注册过 → 一键用它新建账户并直接进入。
2. **默认免密**：新建的账户没有密码，之后每次打开**无需任何验证**直接进。
3. **可选二级凭据**：想要更私密，去 **设置（/me）→ Security**，自己给账户**加密码 / 绑邮箱**。
   一旦设了密码，下次进入会多一步"输入密码"验证；可随时"移除密码"回到免密。
4. **会话保持**：登录状态存在本机的 WebView2 配置目录里，**重开 App 不用重复登录**。

> 一个"账户"= 一个昵称。想多人/多身份，就各建一个昵称账户（都在同一台机器、同一个库里，
> 互相看不到对方的私有工作区，靠权限隔离）。

## 5. 数据在哪里 / 怎么备份迁移

| 内容 | 位置 |
|---|---|
| 数据库（所有工作区/项目/任务/评论） | `runtime\miniplane.sqlite3` |
| 登录密钥（自动生成，勿外传） | `runtime\secret_key` |
| 登录会话（WebView2 配置） | `runtime\webview-profile\` |
| 运行日志（排障用） | `runtime\backend.log` / `frontend.log` / `launcher.log` |

**备份** = 关掉 App 后，把整个 `runtime\` 目录拷走。
**迁移到新机器** = 装好前置（§3）→ 把 `runtime\` 放到项目根 → 双击启动，数据即回来。
（`runtime\` 已在 `.gitignore` 里，不会被提交，含敏感信息，别外发。）

## 6. 日常使用速查

### 6.1 核心对象与流程
- **工作区（Workspace）**：独立的协作空间，数据彼此隔离。首页「新建工作区」创建；左侧竖栏切换。
- **项目（Project）**：在工作区里「新建项目」，填名称 + 标识符（如 `AMI`，任务编号即 `AMI-1`）。
  创建时自动预置五状态：Backlog → Todo → In Progress → Done → Cancelled。
- **任务（Issue）**：项目里新建；点行打开右侧**抽屉**做全部编辑（状态/优先级/指派/标签就地改，
  评论、动态审计时间线都在这里）。
- **批量**：列表勾选多行 → 底部批量条（改状态/优先级/指派/删除逐条下发、失败可"重试失败项"；
  改标签走异步任务）。
- **实时**：同一项目多个窗口自动同步（右上角 ● live）。
- **三级角色**：管理员 / 成员 / 只读（生效角色取工作区与项目中的高者）。

### 6.2 命令面板（特色 A）
- 按 **Ctrl+K**（或点顶栏「搜索 ⌘K」）唤起 → 输入即时过滤 → ↑↓ 选、Enter 打开、Esc 关闭。
- 目前可跳转：我的工作 / 设置 / 各工作区。（后续可扩到"快速建任务"。）

### 6.3 我的工作（特色 B）
- 头像菜单 →「我的工作」，或命令面板搜"我的工作"。
- 跨所有项目汇总**指派给我 / 我创建的**任务，顶部三档筛选：全部 / 指派给我 / 我创建的。
- （"逾期"筛选需任务先有截止日期字段，当前版本暂未做。）

### 6.4 外观：暗色 / 显示大小（特色 H）
- 设置（/me）→ **Appearance**：主题（浅色 / 深色 / 跟随系统）+ 显示大小（小 / 标准 / 大 / 特大）。
- 头像菜单里也有主题快切。设置存本机，重开仍生效。
- 若桌面快捷方式丢失：`powershell -File desktop\make_shortcut.ps1 -Exe "<项目根>\dist\MiniPlane\MiniPlane.exe"`。

## 7. 开发者：跑起来、测试、CI

### 7.1 一键开发栈（改代码用）
```bat
scripts\dev.cmd          :: 起后端(8000)+前端(3000)，就绪后自动开浏览器
scripts\dev.cmd e2e      :: 起栈 → 跑 Playwright 端到端
scripts\dev.cmd status   :: 看两个端口状态
scripts\dev.cmd down     :: 全部停掉
```
开发模式用 **PostgreSQL**（`backend\.env` 的 `DATABASE_URL`），页面与 API 都用 `localhost`。

### 7.2 手动跑（后端 / 前端）
```bat
:: 后端
cd backend && python -m venv .venv && .venv\Scripts\activate
pip install -r requirements\local.txt -r requirements\desktop.txt
copy .env.example .env    :: 填 SECRET_KEY / DATABASE_URL
python manage.py migrate && python manage.py runserver

:: 前端
cd frontend && pnpm install && copy .env.example .env.local && pnpm dev
```

### 7.3 测试与质量门禁
```bat
:: 后端（310 用例）
cd backend
.venv\Scripts\python manage.py test --settings=config.settings.test --noinput
.venv\Scripts\python -m ruff check . && .venv\Scripts\python -m ruff format --check .

:: 前端（98 单测 + 类型 + lint + 构建）
cd frontend && pnpm test && pnpm typecheck && pnpm lint && pnpm build

:: 浏览器端到端（18 用例，需栈已起）
cd frontend && pnpm test:e2e
```

### 7.4 改后端接口的"必做两步"（否则 CI 红）
GitHub Actions 的 backend job 会卡两件事，改后端时务必本地先跑：
1. `ruff format .`（CI 跑 `ruff format --check`，代码没格式化会红）。
2. 改了序列化器/端点/摘要 → 重新生成 OpenAPI 快照：
   `python manage.py spectacular --settings=config.settings.test --file ..\docs\api\openapi.yaml`
   （CI 会 `diff` 仓库里的快照与生成的，不一致就红）。

### 7.5 桌面版与前端源码的关系（重要！）
桌面 App 加载的是 **`dist\` 里预构建的前端**。你改了 `frontend\` 源码后，**必须重跑
`python scripts\package.py` 重建 dist**，改动才会在桌面 App 里生效（开发模式 `pnpm dev` 走源码，
不受此限）。改完 `desktop\launcher.py` 则重跑 `desktop\build.py` 重出 exe。

## 8. FAQ：为什么"看起来很复杂"，怎么变简单

**Q：我双击图标就行，为什么还要装 Python / Node / WebView2？**
A：桌面 App 是"启动器 exe + 本机 Python 后端 + Node 前端 + WebView2 内核"的组合：启动器负责
拉起后端和前端、再开原生窗口。这些运行时装一次即可（§3），日常只管双击图标（§2）。

**Q：我明明注册过，重开又让我登录 / 担心账号丢了？**
A：账号在 `runtime\miniplane.sqlite3` 里，不会丢。之前"重开要重登"是会话没持久化，已修复
（WebView2 配置目录固定到 `runtime\webview-profile`）。现在重开应直接是登录态。

**Q：双击没反应 / 闪退？**
A：看 `runtime\launcher.log`（崩溃会写这里并弹窗提示）。常见：端口 8000/3000 被占（先跑
`scripts\dev.cmd down` 或重启）；缺 WebView2（§3 装一次）。

**Q：改了前端代码，桌面 App 里看不到变化？**
A：见 §7.5——要重跑 `scripts\package.py` 重建 dist。

**Q：桌面版和"浏览器开 localhost:3000"是一回事吗？**
A：不是。桌面版是**原生窗口**、只绑 `127.0.0.1`、用**内嵌 SQLite**、关窗即停服；
早期那个"开浏览器 + 要装 PostgreSQL"的 `start.cmd` 已不是当前用法。

**Q：想彻底单文件、免装任何运行时？**
A：那是下一阶段工程（把 Python/Node 一起冻结进单包，或换 Tauri/Electron 打包）。当前是
"启动器 exe + 本机运行时"的折中，已能双击即用。需要的话可作为后续项排期。

## 9. 名词对照

| 词 | 含义 |
|---|---|
| 工作区 / Workspace | 顶层协作空间，数据隔离单元 |
| 项目 / Project | 工作区下的项目，含五状态与任务 |
| 任务 / Issue | 一条待办，有编号(AMI-1)、状态、优先级、指派人、标签 |
| 动态 / Activity | 任务的变更审计流（倒序） |
| 命令面板 | Ctrl+K 全局搜索/跳转 |
| 桌面 App | pywebview 原生窗口版，双击即用 |
