## 2. Issue 报告（按 debug-repair 格式摘要）

### 🔴 Issue 1 · Anatomy 滚动恢复缺少自动化

- **类型**：回归测试缺口（非产品 bug）。
- **文件**：`frontend/tests/e2e/anatomy-v3.spec.ts`
- **根因**：Phase 4 只做了手工脚本验证，后续改页面可能重新引入滚动归零。
- **方案（已执行 A）**：新增 12 Stage 项目 E2E，验证 Growth 滚到底、切 Structure、切回后恢复。
- **影响**：测试数 40→43；不改变产品代码。

### 🔴 Issue 2 · Drawer 焦点陷阱不完整

- **类型**：无障碍/生命周期错误。
- **文件**：`frontend/components/ui/Drawer.tsx`
- **根因**：打开时聚焦面板、关闭时恢复触发元素，但 Tab/Shift+Tab 可以离开对话框。
- **方案（已执行 A）**：面板级 Tab 陷阱；不改变抽屉状态/URL/业务数据。
- **影响**：键盘焦点保持在 dialog 内；E2E 覆盖。

### 🔴 Issue 3 · Island 最终 exe 快速反向未验证

- **类型**：待验证风险。
- **文件**：`desktop/verify_island_rapid.py`（新增验证脚本）
- **根因**：此前只有状态机单测和视觉原型，没有在最终 exe 上验证快速反向。
- **方案（已执行 A）**：真实 Alt+I 快速切换，检查最终窗口尺寸；测试前备份、测试后恢复 `desktop-config.json`。
- **影响**：不改生产窗口模型；验证结果通过。

### 🔴 Issue 4 · 空态/错误态缺少 E2E

- **类型**：验证缺口。
- **文件**：`frontend/tests/e2e/anatomy-v3.spec.ts`
- **根因**：之前只有正常/密集数据截图。
- **方案（已执行 A）**：空项目 E2E；任务 API 500 时断言 `完整任务加载失败` 与 `图纸暂不完整`。
- **影响**：不把 0 条任务伪装成完整投影。

### 🟡 Issue 5 · zod high 依赖告警

- **类型**：依赖安全债。
- **根因**：zod <4.6.6 的受限集合内存耗尽告警；zod 4 升级破坏成员表单 `z.coerce.number()` 类型推导。
- **方案（已登记 B）**：保持当前版本，限制在已知前端表单使用；下一轮迁移 zod 4 + resolvers 5，补类型与回归测试。
- **影响**：不阻塞第一阶段；不伪造“依赖全绿”。

### 🟡 Issue 6 · 文档 HEAD/状态漂移

- **类型**：交付文档一致性。
- **方案（已执行 A）**：更新 NEXT_CYCLE_PLAN、PHASE5、README 入口；历史报告保留，不做大清洗。
