# UI 模板 v2 · 设计说明（对应四项要求）

> 模板：`ui-design/miniplane-ui-template-v2.html`（高保真静态模板，5 屏可切换：初见 / 我的工程 / 工程台 / 记一笔 / 任务详情）。
> 视觉语言完全保留：暖纸底、32px 蓝图网格、Cormorant Garamond 衬线斜体、钴蓝、0.5px 细线、JetBrains Mono 数据层。
> 本轮零生产代码；模板确认后按 `UI_REDESIGN_PROPOSAL.md` §7 分期实施。

## 1. 如何简化按钮 —— 「行就是按钮」

- **删掉的按钮**：工程卡片的「进入」「开始」、工程台的「设置/日志」盒装按钮、状态行筛选 chips 的边框、「设为当前」常驻按钮、新建项目的模态框入口。
- **替代物**：整行可点击（hover 时浮现 `▸` 与纸面着色）；状态过滤变成**文字+计数**（无边框，选中=钴蓝下划线）；新建=列表末尾的**下一条空白横线**（`＋ 新任务`，点开就地输入，⏎ 完成）。
- 每屏最多一个带强调的动作（顶栏 ✎ 记一笔）；其余全部是文字链接或行内浮现。

## 2. 如何更有设计感 —— 用制图语言替代控件语言

- **进度 = 尺寸标注线**：`|━━━━━|———|` 端点刻度 + 钴蓝填充段，来自建筑图纸的 dimension line，替代圆角进度条；
- **阶段 = 垂直路线图**：站点圆点 + 单线，当前站实心钴蓝 + 软色光环；
- **输入 = 手写横线**：快速记录与初见表单只有底线（无输入框边框），textarea 自带横格纸纹；
- **危险动作 = 红色文字**，无框无底，收进「详情」折叠；
- 页缘笔记式日志（日期在左缘）、`⌘L` / `⌘K` 快捷键标注在动作旁——让快捷键本身成为版面的一部分。

## 3. 如何减少冗杂 —— 三条减法

1. **Team 退场**：左栏底部「协作 · 1 个团队工程」一行虚线区（无团队数据时整块消失），顶栏不再有 ⇄ 切换；工作区管理页保留但只从这一行进入。
2. **默认只读**：路线（Plan）默认是图上的路线，只有点「调整」才出现输入控件；元信息（UUID/时间）与删除全部收进任务详情的 `details` 折叠。
3. **装饰降密度**：坐标标注（N 31°14′）只保留首页一处页眉；FIG 编号、尺寸标注类装饰不再逐区块重复。

## 4. 没用过的人如何上手 —— 「初见」屏

- 第一屏是一张几乎空白的纸：一句话（从一个工程开始）+ 一条手写横线（工程名称）+ ⏎ 即建；
- **全程不出现**「工作区 / 成员 / 角色」字样；说明只有一行小字「数据只留在本机 · 之后随时可加入协作」；
- 建后直达工程台，工程台的任务列表末尾就是「＋ 新任务」空白线——从打开软件到创建工程再到第一个任务，**无需任何学习，零弹窗教程**。

## 交互一览（模板内可操作）

| 位置 | 可操作 |
|---|---|
| 预览铬 | 五屏切换 |
| 我的工程 | 继续行/工程条目 hover；`＋ 新的工程` 就地输入建条目 |
| 工程台 | 状态过滤真实生效；`＋ 新任务` 就地输入；路线「调整」↔ 只读切换 |
| 记一笔 | 「补全」展开 |
| 任务详情 | 评论/动态/详情 三个折叠 |
