# Mini Plane Project Anatomy — Design Pack

这个资料包用于把“项目解剖图”的设计方向交给 AI Agent。

## 文件

- `MINI_PLANE_PROJECT_ANATOMY_SPEC.md`：主技术设计说明，包含设计目标、视觉语汇、领域语义、交互边界、实施阶段、验收标准和参考网址。
- `AGENT_START_HERE.md`：可直接交给 Agent 的启动指令。
- `references/00-concept-direction.png`：本次概念方向示意图；只表达视觉方向，图中项目名称、任务、阶段、百分比等均为虚构样例，不是产品截图。
- `references/01-previous-anatomy-proposal.md`：先前讨论的 A/B 提案，供历史背景参考。
- `references/02-legacy-html-prototype-do-not-copy-layout.html`：当前历史原型，供理解原先尝试；文档要求不要沿用其构图。

## 建议交给 Agent 的方式

把整个文件夹（或 ZIP）交给 Agent，先发送 `AGENT_START_HERE.md` 中的指令。Agent 若在工作仓库内执行，建议将主说明另存至 `docs/design/MINI_PLANE_PROJECT_ANATOMY_SPEC.md`，但**先只提交概念草图，不要改生产页面**。
