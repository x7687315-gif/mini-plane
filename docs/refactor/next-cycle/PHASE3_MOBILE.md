# Phase 3 · 移动端场景与技术决策报告

> 日期：2026-10-29 · 状态：**研究完成，未改监听地址/认证/移动端生产代码**
> 依据：[`NEXT_CYCLE_PLAN.md`](../NEXT_CYCLE_PLAN.md) · [下一周期 preflight](../../research/2026-10-29-next-cycle-preflight.md)
> 安全底线：默认继续只绑 `127.0.0.1`；**禁止**把 `0.0.0.0` 当作移动端默认实现。

## 1. 先回答六个问题

| # | 问题 | 结论 |
|---|---|---|
| 1 | 手机浏览器查看电脑上运行的桌面数据，还是手机独立运行？ | **优先前者（受控查看）**；独立运行/同步不在本轮 |
| 2 | 手机主要做什么？ | 查看当前阶段/NOW/NEXT、快速记 Worklog、切换任务状态；完整编辑 Project/Plan 不作为首版 |

| 4 | 离线/PWA/通知/后台能力？ | 首版不需要；PWA 需安全上下文、Service Worker、缓存/更新策略，成本和风险都更高，暂缓 |

| 6 | Structure 手机端纵向滚动？ | 是。已确认方向：结构图按 Stage 纵向展开，不横向平移整张图；索引/详情下移为单列 |

## 2. 三种方案比较

### 方案 A · 窄屏浏览器适配（本轮建议先做）

- **场景**：桌面窗口变窄、平板/近场浏览器查看；不是手机跨设备访问。
- **实现**：断点下把 Anatomy 三栏改为「索引 → 结构/生长 → 详情」单列；详情固定为可滚动区域；Stage 结构纵向展开；隐藏装饰性辅助线，保留选中/当前/任务计数。
- **优点**：成本最低、不改变安全边界；可作为 B 的视觉基础。
- **限制**：手机仍无法访问 `127.0.0.1` 的桌面数据；只解决窄视口可用性。
- **工作量**：中低；主要是布局/断点与 E2E 视口用例。
- **回退**：移除断点样式即可，不影响桌面。

### 方案 B · 受控网络访问（建议下一实验，先不实现）

- **场景**：手机在同一 tailnet 内查看桌面项目、快速记一笔。
- **实现**：应用继续绑 `127.0.0.1`；用户显式启用 Tailscale Serve（`localhost:3000` → tailnet HTTPS），不把服务直接监听在局域网/公网。
- **必须补齐**：登录会话、CSRF/Origin 白名单、连接状态、失败恢复、设备/网络说明、关闭开关；不启用 Funnel/公网暴露。
- **优点**：复用现有前后端与 SQLite；不需要云同步；Tailscale 负责加密与设备身份边界。
- **风险**：新增外部网络层与运维步骤；手机浏览器 PNA/安全上下文差异；会话被他人设备复用的风险；需要真实手机测试。
- **工作量**：中高；不能作为默认开启。
- **回退**：关闭 Serve/停止 tailnet 暴露，应用仍只在本机可用。

### 方案 C · PWA / 独立移动端（暂缓）

- **场景**：脱离桌面进程、独立安装、离线、通知、长期跨设备使用。
- **代价**：安全上下文/Service Worker/缓存与更新、数据同步和冲突、认证与密钥、桌面 SQLite 与移动端数据关系；维护负担最高。
- **结论**：本轮不启动；没有真实的离线/通知/独立运行需求证据前，不引入。

## 3. 推荐路线

1. **先做 A**：窄屏只读 + Structure 纵向阅读；不改认证/网络。
2. **B 作为显式实验**：在 A 的视觉基础上，用 Tailscale Serve 验证“手机查看 + 快速记录”，默认关闭、文档化、可回退。
3. **C 暂缓**：等 B 的真实使用数据证明需要离线/通知/独立运行时再评估。

## 4. 低保真流程建议

```text
手机窄屏 / Structure
┌─────────────────────────────┐
│ AVXD4 · Anatomy V3          │  ← 项目名 + 当前阶段
│ 63%  STAGE 工作台与协作      │
│ [Stage 01] [02] [03] [04•]  │  ← 横向 Stage chips（只选中，不画整图）
├─────────────────────────────┤
│ 04 工作台与协作              │
│ 62% · 5 TASK                │
│  NOW  结构视图：整体与爆炸模块 │
│  NEXT 图纸全量任务读取        │
│  [任务 01] [任务 02] ...     │  ← 任务行，点击打开底部详情
├─────────────────────────────┤
│ 03 统一契约 …                │  ← Stage 纵向继续
└─────────────────────────────┘
```

- 选中 Stage 的详情用底部 sheet 或同屏下方卡片；关闭后回到原滚动位置与选中 Stage。
- 快速记 Worklog：底部固定「记一笔」，只保留标题/完成内容/结论/下一步/阻塞；提交后回到原 Stage 与滚动位置。
- 不把桌面三栏缩成一个窄三栏；不隐藏 NOW/NEXT/任务计数。

## 5. 安全边界与验证清单

- 默认 `127.0.0.1`；不把 `0.0.0.0`、公网 Funnel、LAN 明文作为默认。
- B 方案必须使用受控网络/TLS；会话 cookie 不写入 URL；Origin/CSRF 白名单保持同源策略。
- 真实手机测试：登录/过期、弱网/断线、快速记一笔、关闭/重开、错误提示、无权限项目。
- 禁止把项目数据/日志带到第三方托管；Tailscale 只做网络层，数据仍在桌面 SQLite。
- 回退：关闭 Serve → 恢复仅本机；移动端样式可独立开关，不影响桌面。

## 6. 结论

**推荐 A 立即进入后续视觉/实现；B 作为受控实验在 A 后验证；C 暂缓。** 本阶段不修改监听、认证、数据库或移动端生产代码；下一步若进入 A，需先做窄屏低保真/真实样机与 Structure 纵向可读性验证。
