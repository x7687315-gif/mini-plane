# v0.1.0 — Mini Plane 后端 MVP

发布日期：2026-09-12（Sprint 0–8 全部完成）

## 这是什么

仿 [Plane](https://github.com/makeplane/plane) 的迷你项目管理软件后端：双人学习项目，
从 0 实现多租户 SaaS 的完整业务链路（Django 5.2 LTS + DRF + PostgreSQL 16）。

## MVP 功能清单

- **认证**：注册 / 登录 / 登出 / 当前用户（Session + CSRF，CORS 跨端口联调一次配通）
- **多租户工作区**：Workspace CRUD + 成员管理（ADMIN/MEMBER/VIEWER 三级角色，
  owner 与最后一个 ADMIN 保护）；Project CRUD + 项目成员 + 创建即预置五个默认状态
- **Issue 全生命周期**：CRUD、per-project 发号（`#1 #2`，事务内 `select_for_update` 并发安全）、
  状态/优先级/指派/标签；Label CRUD；State 只读
- **协作**：评论（作者/Admin 编辑权限）；Activity 活动流（每次变更留痕，old→new diff）
- **查询引擎**：Issue 列表多值过滤（state/priority/assignee/labels）+ 搜索 + 排序白名单 +
  统一分页（5000 条数据 P95 < 300ms，索引经 EXPLAIN 验证）
- **缓存与异步**：Project 详情缓存（主动失效 + TTL 兜底）；Celery 任务（评论通知、
  Issue 批量操作 + 任务状态查询；Retry/幂等）
- **实时推送**：WebSocket 项目房间（Channels + daphne），`issue.updated` / `comment.created`
  事件、心跳、4401/4404 关闭码语义
- **工程化**：统一错误体/分页体、OpenAPI schema（drf-spectacular，快照入库 + CI 防漂移）、
  277 个测试（权限矩阵逐格覆盖 + N+1 回归防线）、Docker Compose 全套编排、GitHub Actions CI

## 质量

- 测试 277 全绿；`ruff check` / `ruff format --check` 零告警；迁移无漂移
- 接口契约（docs/api/00–08）与实现一致；404 防枚举贯穿 HTTP 与 WS

## 已知边界（二期）

- 全文检索（pg_trgm）、跨项目搜索、软删除/归档
- Label 变更不产生活动记录；通知只落库（邮件/推送二期）
- 多进程部署必须配 `CHANNEL_REDIS_URL`（08 契约警告）
- 前端由同学另行开发中
