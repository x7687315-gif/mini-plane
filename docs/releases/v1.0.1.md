> 这是 v1.0.0 之后的稳定性补丁：不新增产品范围，集中完成 Anatomy、Island、桌面生命周期与工程门禁的收尾。

## 下载

GitHub Release：<https://github.com/x7687315-gif/mini-plane/releases/tag/v1.0.1>

**`mini-plane-1.0.1-local.zip`** —— 本地单机版：

```text
1) 双击 setup.cmd    首次：生成 SECRET_KEY、写配置、建 venv、装依赖、迁移数据库
2) 双击 start.cmd    启动后端 + 前端，打开 http://127.0.0.1:3000
                     stop.cmd 一键停止
```

需要：Windows 10/11 · Python 3.12+ · Node.js 20+ · PostgreSQL 16
