# Mini Plane v1.0.0 — Personal Engineering Management Platform

> **本地运行的个人工程管理系统。** 前端 + 后端 + 数据库都在你自己的机器上，数据不出本机。
> 这一版把项目从「Plane 的简化复刻」完整演进成「以个人工程管理为第一体验、同时保留团队协作能力的本地工程管理系统」。

## 下载

**`mini-plane-1.0.0-local.zip`** —— 本地单机版，解压后按内附 README 操作：

```text
1) 双击 setup.cmd    首次：随机生成 SECRET_KEY、写配置、建 venv、装依赖、迁移数据库
2) 双击 start.cmd    启动后端 + 前端，自动打开 http://127.0.0.1:3000
                     stop.cmd 一键停止
```

需要：Windows 10/11 · Python 3.12+ · Node.js 20+ · PostgreSQL 16

> 想要**双击即用的桌面窗口版**（原生 pywebview + 置顶的 Island 悬浮窗）？按
> `desktop/README.md` 两条命令在本机构建：`python scripts\package.py` → `desktop\build.py`。

## 三个核心概念

| | |
|---|---|
| **Task 是计划，Worklog 是证据** | 任务写"打算做"，工程日志写"实际做了什么、结论如何"——这是与一般任务管理软件最本质的区别 |
| **百分比是辅助，阶段与 NOW 才是主信息** | Island 上最显眼的是当前阶段 / NOW / NEXT / TODAY |
| **Markdown 是原始事实，Mini Plane 是结构化索引** | AI 写的 devlog 不被数据库取代，系统负责汇总成"今天工程进行到哪了" |

## 这一版有什么

**个人工程层（默认体验）**

- **我的工程**首页：跨项目聚合，NOW / NEXT / 今日日志 / Agent 运行态（单条 SQL 聚合，无 N+1）
- **Global Plan / Stage**：阶段路线 + 权重 + `Σ(权重×进度)` 加权进度 + 当前/下一阶段
- **工程日志 Worklog**：date / 标题 / 摘要 / 详情 / 结论 / 下一步 / 阻塞 / 来源
- **Engineering Island**：一张图纸 = 一个项目，左右滑动翻图纸；Resting / Focus 两态；
  图纸角标（FIG / SHEET / REV / 十字准星）；桌面版可作**置顶悬浮窗**（`Alt+I` 唤出）
- **登录页记住上次是谁**：点一下直接进，免密/需密码/账户已删三种情况都有明确降级

**团队协作层（保留但降级为协作基础设施）**

- 工作区 · 成员 · 三级角色 · 项目 · 任务 · 评论 · 动态审计 · 实时协作 · 批量操作
- 顶栏 ⇄ 按钮在两层之间切换，记住你上次停留的团队位置

**给 AI Agent 的接入**

- 独立于用户会话的 **Agent Token**（明文只显示一次，服务端只存 SHA-256 哈希）
- scope 白名单只有 5 项：读项目 / 读任务 / 写任务 / 写日志 / 更新阶段进度
  ——**没有删除、成员管理、角色变更，也不能改 Global Plan 的结构**
- 所有写操作支持 `Idempotency-Key`（Agent 重试不会产生重复数据）
- 会话状态在事务内广播 `agent.session`，**界面与 Island 立刻变 `AGENT · RUNNING`**

## 质量

| 类别 | 数量 |
|------|------|
| 后端测试 | **334** |
| 前端单测（零依赖 `node --test`） | **129** |
| 浏览器 E2E（Playwright + 真实 Chrome） | **33** |
| 远端 CI | backend / frontend 双 job，含 ruff（backend·desktop·scripts）、类型、单测、生产构建、OpenAPI 快照 diff、迁移漂移检查 |

其中一条 E2E 是完整的**闭环链路**：建 Agent Token → 换身份起会话 → **Island 不刷新就变成 RUNNING**
（`/projects/mine/` 没有轮询，所以这条用例只有 WebSocket 真把事件推到界面才会通过）。
