# v0.2.0 — Mini Plane 前端 MVP（全栈打通）

发布日期：2026-09-17（前端 Sprint 0–8 全部完成）

## 这是什么

[v0.1.0](v0.1.0.md) 交付了后端 MVP，本版交付**前端 MVP**：从登录到改状态、评论、
批量操作、实时推送的完整可交互界面。到这里，`docker compose up --build -d`
起来的就是一套能真正用起来的全栈应用。

设计语言是自定的 **Blueprint Editorial（蓝图编辑风）**：暖灰白 `#F4F1EA` +
炭黑 `#1B1A17` + 钴蓝 `#1F3FA8`，Cormorant Garamond italic 做装饰、Inter 做正文，
0.5px 直角边框 + 32px 网格底纹。
**反模板**：不引入组件库、不引入图标库（全部自绘 inline SVG）、不做暗色模式、
不用渐变/阴影/毛玻璃/emoji、不用 spinner（一律骨架屏）、不做 hover tooltip。

## 一键起全套

```bash
docker compose up --build -d
# 前端        http://localhost:3000/                ← 请用 localhost，不要用 127.0.0.1
# 健康检查    http://127.0.0.1:8000/api/v1/health/
# Swagger     http://127.0.0.1:8000/api/docs/
# WebSocket   ws://127.0.0.1:8001/ws/...
```

> 前端镜像的 `NEXT_PUBLIC_API_BASE` / `NEXT_PUBLIC_WS_BASE` 是**构建期**常量
> （Next 会把它们内联进客户端 bundle）。改地址要 `docker compose build frontend`。

## 已知边界（二期）

**未做端到端验收**（本机没有可跑的 Postgres / Docker，是这一版最大的诚实话）：
登录闭环、评论时间线、5000 条首屏性能、批量改标签、A 改 B 实时收到 —— 这五项
都需要真实后端才能验。策略层（纯函数：文案映射、权限矩阵、URL 解析、轮询停止条件、
重连退避与关闭码）已有 98 条单测覆盖；交互层已逐条写入各 Sprint devlog 的验收表并标注。

其余：

- **E2E（Playwright）与组件测试未落地**：位置已留在 Sprint 8 的 CI 设计里，
  但真正跑起来需要浏览器二进制 + 后端。
- **`docs/assets/` 仍是静态视觉稿**（`src/*.html` 渲染），不是真实产品截图。
- **批量失败的重试入口**未做（只提示失败数与首个原因）。
- **Lighthouse ≥ 90 未实测**：需要完整栈；本次只给出了 bundle 体积的客观数据。
- 契约 09（前端接入手册）保持"随前端进展回填"状态。

## 破坏性变更

无。本版只新增前端，后端接口与数据结构未改动（后端仅补了 `docker-compose.yml`
里 `web` 服务的 healthcheck，以及默认 CORS/CSRF 白名单增加 `127.0.0.1:3000`）。
